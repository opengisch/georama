# Quick-start Guide

Set up **Georama** using Docker with minimal effort, either for local development or for a production deployment.

    The [README.md](https://github.com/opengisch/georama#readme) of the repository.

Choose the guide matching your use case:

- [:material-laptop: Local Development](local_development/index.md): run the full development
  stack with Docker Compose, live reload and example content.
- [:material-server: Production Deployment](production.md): build the production image
  and run it against your own infrastructure.
- [:material-cog: Environment Variables](environment.md): the variables used to
  configure Georama, in development and in production.
- [:material-link: User Endpoints](endpoints.md): the WMS and OGC API - Features
