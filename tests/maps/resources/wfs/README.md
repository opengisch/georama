# Exemplaric sources

## WFS

The sources were fetched by https://map.geo.bs.ch/mapserv_proxy? and represent the content we need to satisfy
with our WFS too.

Mainly this is about the following operations:
- [GetCapabilities](https://map.geo.bs.ch/mapserv_proxy?ogcserver=WMS+BS+%28edit%29&service=WFS&request=GetCapabilities&version=2.0.0)
- [DescribeFeatureType](https://map.geo.bs.ch/mapserv_proxy?ogcserver=WMS+BS+%28edit%29&service=WFS&request=DescribeFeatureType&version=2.0.0)

- [DescribeStoredQueries](https://map.geo.bs.ch/mapserv_proxy?ogcserver=WMS+BS+%28edit%29&service=WFS&request=DescribeStoredQueries&version=2.0.0)
